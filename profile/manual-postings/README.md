# Manual postings

Roles you found yourself (LinkedIn, a friend, a company's own careers page),
**not** sourced by the automated sweep. They live here when they're not on a
supported ATS (Greenhouse / Lever / Ashby / Workable / SmartRecruiters) — the
sweep can't watch custom career sites, and they must not go in `targets.yaml`
(a wrong slug fetches the wrong board).

This is a holding area — your own notes on a posting, which is allowed (not
scraping). Each file carries the JD text, a fit read against the evidence bank
(with `ev:` citations and `[SHORTFALL]`s), and a `status`
(new / hold / drafted / passed).

**The way in is `/add`** (PRD §14): paste the JD, get a fit read, and decide.
Pursue → a tailored markdown draft, reviewed live in the same session. Hold or
pass → the note stays here with its status. Never auto-submitted; you apply by
hand and run `/log`.
